# Historical Compact 99,000-Row Evidence

This directory preserves the pre-remediation `compact` demonstration that previously occupied
`reports/final/yf2-100k/`. It is deliberately labelled by its actual size: `220 sensors x 450
samples = 99,000` telemetry rows at 7.5 hours.

It is **not** the exact-100k deliverable. The exact 100,000-row evidence is in
`reports/final/yf2-100k/`. The compact scenario remains supported by the current generator via
`--scenario-set compact --duration 7.5`; this directory is retained for historical comparison and
traceability.
